# Путь к ЕГЭ · Тёмный мир знаний

Неофициальный фанатский образовательный инструмент, вдохновлённый DELTARUNE. React 19, TypeScript, Vite, React Router; настольная оболочка Electron. Иллюстрации оригинальные, созданы средствами SVG/CSS. Спрайты, музыка и реплики игры не используются.

## Программа Windows (.exe)

Теперь проект поддерживает отдельное настольное окно на Electron. Переносная версия Windows x64 не требует браузера, Node.js или запущенного сервера и работает офлайн. Готовые сборки публикуются через [GitHub Releases](https://github.com/Dezertir098/CodexTest/releases) после успешной проверки workflow. Отправка исходников сама по себе не означает, что выпуск уже собран.

**Скачать:** Releases → Assets → `Put-k-EGE-<версия>-x64-portable.exe`. Прогресс хранится в `%APPDATA%\PutKEGE`; для переноса из браузера используйте экспорт/импорт. ИИ в офлайн-сборку не включён. [Подробности и команды сборки](docs/desktop.md).

## Запуск

Нужны Node.js 20.19+ или 22.12+ и npm. Проверено на Node.js 24.19.0 / npm 11.9.0.

```bash
cd /workspace/CodexTest
npm ci
npm run dev -- --port 5173
```

Vite слушает порт 5173. В облачном окружении для запуска сервера может требоваться разрешение выполнения вне сетевой песочницы. Приложение не опубликовано автоматически. Для размещения на собственном хостинге: `npm run build`, затем обслуживать `dist/` с перенаправлением неизвестных путей на `index.html` (для React Router).

```bash
npm test             # Проверки банка, форматов ответов, прогресса и повторений
npm run build       # TypeScript + production-сборка
npm run test:e2e    # Настоящие пользовательские сценарии в Chromium
```

Playwright использует системный `/usr/bin/chromium`, если он есть. На другой машине сначала выполните `npx playwright install chromium`; при необходимости задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Сервер для e2e запускается автоматически, если порт 5173 свободен.

## Что работает

- Главная с реальными показателями, последней темой и рекомендациями.
- Открытая карта обучения с четырьмя статусами, поиск и фильтры библиотеки.
- Урок: основы → подсвеченный пример → алгоритм → практика с помощью → самостоятельная практика → проверка понимания → завершение.
- 70 авторских упражнений с ответами, подсказками и объяснениями. Выбор одного/нескольких ответов, ввод слова/цифр, соответствие, выделение слов, выбор позиций запятых, исправление предложения. Письменная работа вынесена в отдельный редактор; она не оценивается как тест.
- Контекстная панель «Не понял»: простое объяснение, другой пример, алгоритм, отличие похожих случаев, базовые понятия, разбор отправленного ответа, поиск по готовым материалам.
- Диагностика: 13 вопросов, по одному на блок; можно пропустить.
- Адаптивная практика учитывает результаты, помощь, трудность, повторные ошибки и срок повторения.
- Работа над ошибками: после самостоятельного верного решения задание выходит из списка. Решение с помощью не закрывает ошибку.
- Повторение после самостоятельных успехов: 1, 2, 4, 8, 16, 30 дней; с помощью — 1 день; ошибка — 10 минут.
- Учебная работа: 26 вопросов (по два на блок, с подбором по истории), 60 минут, навигация, отметки, автосохранение ответов и абсолютного срока, автоматическое завершение, разбор. Без подсказок, персонажей и анимации.
- Мастерская сочинения: оригинальный исходный текст, шесть методических опор, редактор, подсчёт слов и абзацев, автосохранение.
- Статистика, история завершённых уроков, серия самостоятельных ответов и небольшие достижения.
- Настройки текста, анимаций, персонажей, концентрации, сложности и длительности сессии.
- Экспорт/импорт JSON с проверкой структуры и подтверждением замены; сброс с подтверждением. Повреждённое локальное сохранение не перезаписывается молча.
- Адаптивный интерфейс, подписи полей, клавиатурный фокус, закрытие помощи Escape, учёт prefers-reduced-motion.

## Требования ФИПИ: важное ограничение

Официальная страница: https://fipi.ru/ege/demoversii-specifikacii-kodifikatory

При разработке запрос к ФИПИ получил `CONNECT tunnel failed, response 403` от сетевого прокси. **Документы 2027 года не были прочитаны и подтверждены.** Нумерация в карточках — неподтверждённый ориентир по предыдущей структуре. Банк не выдаётся за задания ФИПИ.

Поэтому экзаменационный раздел намеренно обозначен как **учебная работа**, а не полноценный официальный пробник ЕГЭ-2027. 26 вопросов, 60 минут и один балл за ответ — локальные учебные параметры. Здесь нет официальных первичных баллов, шкалы перевода, подтверждённых критериев сочинения или утверждений о соответствии всем экзаменационным форматам. До добавления официального пробника нужно получить документы, сверить нумерацию, длительность, типы ответов, частичные баллы и критерии, добавить соответствующий вариант и отдельные тесты оценивания.

Содержание проверялось при разработке, но независимая методическая экспертиза не проводилась. Банк из 70 заданий следует расширять для подготовки на протяжении нескольких месяцев. Текущий курс не является гарантией балла 85–90+.

## Необязательный ИИ-наставник

Без ИИ всё основное обучение работает локально. Для свободных вопросов реализован серверный адаптер OpenAI; реальные запросы к провайдеру без ключа не проверялись.

1. На сервере безопасно задайте `TUTOR_API_KEY` (значение не помещать в исходники, браузер или переменные `VITE_*`). По желанию задайте `TUTOR_MODEL`, по умолчанию `gpt-4.1-mini`.
2. В отдельном терминале выполните `npm run tutor`. Он слушает **только 127.0.0.1:8787**.
3. Запустите Vite обычным способом. `/api/tutor` проксируется на сервер наставника.
4. В панели помощи откройте «Задать свой вопрос» и нажмите «Спросить подключённого ИИ». Отправка происходит только по нажатию пользователя. Отправляются вопрос, тема, условие, уже отправленный ответ и список показанных объяснений. Правильный ответ нерешённого упражнения не отправляется.

Нужен исходящий HTTPS-доступ к `api.openai.com`. В облаке используйте поддерживаемое серверное/прокси-связывание секрета `TUTOR_API_KEY` с этим доменом. Если ключа нет, сервер возвращает 503 без обращения к провайдеру. Для публичного размещения потребуется отдельная аутентификация и ограничение запросов: текущий сервер рассчитан на личную локальную работу. Vite production-preview не проксирует ИИ; при развёртывании нужен собственный reverse proxy `/api/tutor`.

Локальный поиск по вопросу не является искусственным интеллектом и явно подписан. Оценка сочинения ИИ не реализована; редактор не проверяет автоматически орфографию, грамматику и субъективные критерии.

## Хранение и приватность

Основное приложение не требует сервера, аккаунта или ключей. Прогресс, черновик, ответы пробной работы и настройки хранятся в `localStorage` (`dark-world-progress-v1`). Очистка данных браузера удаляет их; перенос между устройствами — экспорт/импорт. Синхронизации с облаком нет. Сохраняются ответы сразу после проверки, ответы пробной работы и черновик — при изменении. Позиция внутри незавершённого урока/обычной тренировки при перезагрузке не восстанавливается; уже проверенные ответы сохраняются.

## Структура

```text
src/
  App.tsx                 # Общая оболочка, навигация и маршруты
  pages/                  # Главная, карта, библиотека, урок, тренажёр,
                          # сочинение, статистика, настройки
  Exam.tsx                # Учебная работа с таймером и разбором
  components/
    AnswerInput.tsx       # Разные способы ввода ответа
    Practice.tsx          # Цикл решения и обратная связь
    Help.tsx              # Контекстная помощь и необязательный ИИ
    Character.tsx         # Собственные SVG-портреты
  data/
    curriculum.ts         # 13 уроков, типы, основной банк, источники
    extra.ts              # Дополнительные авторские упражнения
  lib/
    engine.ts             # Проверка, диагностика ошибок, повторения,
                          # подбор, статистика, проверка импорта
    store.tsx             # Постоянное хранилище и восстановление
    tutor.ts              # Интерфейс подключаемого провайдера
    engine.test.ts        # Модульные проверки
  styles.css              # Адаптивная дизайн-система
server/tutor.mjs           # Необязательный сервер ИИ без клиентских ключей
e2e/app.spec.ts            # Проверки сценариев настоящим браузером
docs/screenshots/          # Снимки интерфейса
```

Для новой темы добавьте объект `Topic` и упражнения `Exercise`; интерфейс подхватит их. ID существующих заданий должны оставаться стабильными, иначе старый прогресс потеряет связь с банком. Схема прогресса версионирована; при несовместимом изменении нужна миграция, а не молчаливый сброс.
