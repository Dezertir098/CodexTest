## Windows 10/11 · x64 · переносная версия

Скачайте **Put-k-EGE-1.1.0-x64-portable.exe** из Assets и запустите. Установка Node.js, браузера или зависимостей не нужна. «Source code» — исходники для разработчика, а не готовая программа.

Уроки, 70 авторских упражнений, контекстные объяснения, повторения, учебная пробная работа и редактор сочинения работают офлайн. Прогресс сохраняется в профиле Windows: `%APPDATA%\PutKEGE`. Перед переносом на другой компьютер используйте экспорт в настройках приложения. Прогресс из веб-браузера можно перенести через экспорт/импорт.

Эта любительская сборка не имеет сертификата подписи кода: Windows может показать предупреждение о неизвестном издателе. Файл SHA256SUMS.txt позволяет сверить целостность скачанного файла.

Точное соответствие ЕГЭ-2027 не подтверждено документами ФИПИ. Пробная работа учебная, автоматической экзаменационной оценки сочинения нет. ИИ-наставник в офлайн-версии не подключён.
